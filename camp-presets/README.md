# Test camps

Two made-up camps that show the app fits different Burning Man camps. Fake data only.

| | Lantern Crew | Bass Canyon |
|---|---|---|
| Camp type | Art support camp | Theme camp (placed) |
| People | 20 | 150 |
| Packs | Art, Fire and flame, Kitchen | Sound (pulls in Big power), Kitchen, Fire and flame, Workshops |
| Dues | $300 | $650 |

To try one locally, copy its file over `camp.config.ts` (fix the import path to
`./src/lib/camp-config`), then `pnpm seed`. `pnpm camp:setup` can also write one from scratch.
